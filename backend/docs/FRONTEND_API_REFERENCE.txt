================================================================================
  QUICK REFERENCE — INTERVIEW FLOW (API Call Order)
================================================================================

  1. Candidate applies       →  POST /api/v1/campaigns/{campaign_id}/apply
  2. Candidate starts         →  POST /api/v1/interviews/{interview_id}/start
  3. Load questions           →  GET  /api/v1/interviews/{interview_id}/questions
  4. Submit each answer       →  POST /api/v1/interviews/{interview_id}/responses  (repeat per question)
  5. Finish interview         →  POST /api/v1/interviews/{interview_id}/complete
  6. View results             →  GET  /api/v1/interviews/{interview_id}/results


================================================================================
  QUICK REFERENCE — AUTHENTICATION FLOW
================================================================================

  1. Sign up or Sign in      →  POST /api/v1/auth/signup  or  /api/v1/auth/signin
  2. Store access_token and refresh_token in localStorage
  3. Send token in every request:  Authorization: Bearer <access_token>
  4. When access_token expires, refresh it:  POST /api/v1/auth/refresh
  5. If refresh also fails, redirect to login page
